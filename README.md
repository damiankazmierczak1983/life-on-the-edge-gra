# LIFE ON THE EDGE 12.0 — gra przeglądarkowa

Wersja edukacyjna bez serwera i bez płatnego hostingu.

## Uruchomienie

Po włączeniu GitHub Pages w Settings → Pages → Deploy from a branch → main / (root), gra będzie pod adresem:

https://damiankazmierczak1983.github.io/life-on-the-edge-gra/

Panel nauczyciela: https://damiankazmierczak1983.github.io/life-on-the-edge-gra/panel-nauczyciela.html

## Ograniczenia

- Postępy przechowywane są lokalnie w przeglądarce.
- Uczniowie eksportują wyniki do JSON, a nauczyciel importuje je w panelu.
- Nie ma centralnego rankingu na żywo ani serwerowej weryfikacji wyników.
- Kod źródłowy i odpowiedzi są publicznie dostępne; nie jest to zabezpieczony egzamin.
- Nie publikuj danych osobowych ani haseł.
- Obraz `okladka.png` nie został jeszcze przeniesiony z prywatnego repozytorium; gra użyje tła gradientowego, dopóki obraz nie zostanie dodany.
